# Портфолио Вероники — вайбкодер

Одностраничный сайт-портфолио: проекты, найденные баги, как я работаю с ИИ.

Собран с помощью Claude Code: HTML, CSS и JavaScript без сборщиков и фреймворков.
Анимации (терминал на первом экране, счётчик выручки, появление блоков) написаны на чистом JS
с `IntersectionObserver` и `requestAnimationFrame`, учитывают настройку «уменьшить движение».

Проекты из портфолио:
- https://abalife-center.ru — сайт детского нейроцентра с формой заявок на PHP
- https://novikov-school-now.github.io/proverka/ — интерактивная проверка на JavaScript
- https://novikov-school-now.github.io/kto-naprotiv/ — определитель для онлайн-курса
