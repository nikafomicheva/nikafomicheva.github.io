Сайт детского нейроцентра с нуля

«ABA лайф», Москва · июль — сентябрь 2026 · всё сделала одна, с Claude Code

Центр только открылся: его никто не знал, отзывов не было. Сайт читают встревоженные родители особенных детей, поэтому нужен спокойный тон и мягкий первый шаг. А Яндекс строго проверяет медицинскую тему и не пропускает многие слова.

Маркетинговое задание

  • Целевое действие: запись на бесплатный разбор
  • Лестница цены: разбор 0 ₽ → диагностика 2 500 ₽ → абонемент
  • Отдельная страница для школьников под свою рекламу
  • Видеть, откуда пришла каждая заявка
  • Данные родителей хранить в России по закону
  • ВёрсткаHTML, CSS, JavaScript без сборщиков: главная, страница для школьников, политика конфиденциальности, чек-лист в обмен на контакт. Адаптив под телефон.
  • Форма заявокОтправка через fetch, ответ сервера в JSON. Обработчик send.php на сервере в РФ: защита от спама (скрытое поле, не больше одной заявки в 20 секунд с одного адреса, проверка источника запроса), лог заявок вне корня сайта. В письме видно, с какой страницы пришла заявка.
  • Домен и хостингДомен на reg.ru, DNS, SSL от Let’s Encrypt, редирект на https, почта домена с DKIM и DMARC, чтобы письма с заявками не попадали в спам.
  • АналитикаЯндекс Метрика, цели прямо в коде: отправка формы, клик по телефону, Telegram и WhatsApp. UTM-метки на рекламных ссылках.
  • SEOsitemap.xml, robots.txt, title и description, подтверждение в Яндекс Вебмастере, карта с карточкой организации на странице.
  • ДеплойВыкладка архивом через панель хостинга, после каждой выкладки проверяю живую страницу снаружи. Чек-лист на случай переезда центра: сайт, карты, реклама, документы.

Маркетинг вокруг сайта

Сайт сам по себе заявок не приносит, поэтому трафик на него я тоже вела сама.

  • Анализ конкурентов. Разобрала 8 центров на Авито: цены, предложения, тексты, слабые места.
  • Семантическое ядро через Wordstat. Собрала, по каким словам родители ищут занятия, посчитала спрос и сезонность. Эти слова легли в тексты сайта, объявлений и в рекламу.
  • Тексты объявлений. Написала объявления для Авито и Яндекс Директа. На Авито переписала текст в 3 раза короче, когда увидела, что люди не кликают по объявлению в ленте.
  • Картинки для карточек. Сделала обложки объявлений и оформила карточку центра на Яндекс Картах.

Баги, которые я нашла и починила

ИИ быстро пишет код, но проверять его приходится человеку. Вот что ломалось на живых проектах и как я это нашла.

Сайт нейроцентра

Сайт не открывался у клиентов с Android

Причина
Сайт стоял на Cloudflare, а российские провайдеры его замедляют.
Решение
Перенесла на российский хостинг, переключила DNS, выпустила сертификат.

Сайт нейроцентра

Не выпускался SSL-сертификат

Лог
SERVFAIL looking up CAA
Причина
Технический адрес хостинга стоял в списке псевдонимов сайта.
Решение
Убрала псевдоним, сертификат выпустился, включила редирект на https.

Сайт нейроцентра

Форма могла показать «ошибку», хотя заявка ушла

Причина
Хостинг печатает предупреждения PHP прямо в ответ сервера, и JSON ломается.
Решение
Отключила показ ошибок в ответе, пишу их в отдельный лог, закрытый из интернета.

Сайт нейроцентра

Исправление на сервере «не применялось»

Причина
Панель хостинга не перезаписывает одиночный файл при загрузке: на сервере оставался старый send.php.
Решение
Нашла по дате файла. Выкладываю архивом с распаковкой, правило записала в инструкцию по деплою.

Сайт нейроцентра

Яндекс Бизнес не пропускал карточку и рекламу центра

Причина
На сайте и в карточке были медицинские термины, а эту тему Яндекс проверяет строго.
Решение
Вычистила термины с сайта и из карточки, заменила их понятными родителям словами. Модерацию прошли.

Сайт нейроцентра

Метрика не считала посетителей

Причина
Опечатка в фильтре счётчика отсекала визиты.
Решение
Нашла и исправила, сверила цифры с заявками.

Онлайн-школа Виталия Новикова

Ссылки открывались внутри урока, а не в новой вкладке

Причина
Страница встроена в онлайн-курс через iframe, а у ссылок не было target="_blank".
Решение
Заметила при проверке с телефона, добавила атрибут, проверила живую страницу.

Как я работаю с ИИ

ИИ пишет код, а я отвечаю за то, чтобы получилось то, что нужно бизнесу, и чтобы это работало.

  1. Задача

    Выясняю, какое целевое действие нужно бизнесу, кто клиент и откуда он придёт.

  2. Структура

    Раскладываю страницу на блоки: первый экран, призыв к действию, доверие, возражения, форма.

  3. Промпт

    Ставлю ИИ задачу по одному блоку: контекст, ограничения, как проверить результат.

  4. Генерация

    Работаю в Claude Code: он видит все файлы проекта и сам вносит правки.

  5. Проверка

    Смотрю на телефоне и компьютере, отправляю тестовую заявку, читаю логи и ответы сервера.

  6. Правки

    Итерирую, пока не будет работать и хорошо выглядеть. Решения записываю, чтобы не наступать на те же грабли.

Память проекта. У каждого проекта свои правила и заметки для ИИ: как устроен сайт, как выкладывать, что уже пробовали.

Свои инструменты. Настраиваю ИИ-помощников под задачи: отдельные проверяют код и дизайн, отдельные ищут информацию.

Проверка снаружи. После выкладки проверяю живую страницу: ответ сервера, содержимое, мобильную версию.

Git. Страницы на GitHub Pages выкладываю через репозиторий: коммит, и через минуту обновление в сети.
